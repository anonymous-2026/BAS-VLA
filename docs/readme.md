# BAS-VLA project website assets

This folder stores the static GitHub Pages project website for the anonymous BAS-VLA release.

## Layout

- `index.html`: project homepage.
- `static/css/index.css`: BAS-VLA theme and layout overrides.
- `static/js/index.js`: small scroll-to-top helper.
- `static/images/bas_vla_logo.png`: project logo used on the website header.
- `static/images/bas_vla_icon.png`: favicon.
- `static/images/paper/`: still images extracted or copied from the submitted paper.
- `static/paper.pdf`: anonymous paper PDF linked from the homepage.

The page intentionally uses still images only.

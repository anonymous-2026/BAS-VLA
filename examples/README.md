# Examples

This folder contains minimal release-facing command examples for BAS-VLA.

The examples assume that runtime paths are provided through environment variables from `.env.example`.

## Included examples

- `run_openpi_semantic_break.sh`
  - one local OpenPI + LIBERO semantic-break run
- `run_openpi_appearance_shift.sh`
  - one local OpenPI + LIBERO appearance-shift run
- `run_openvla_oft_semantic_break.sh`
  - one local OpenVLA-OFT + LIBERO semantic-break run
- `train_breaking_adapter.sh`
  - one local offline adapter-training command
